01 Foundations

Universal rules that everything else inherits.

Single source of truth for tokens
All color, radius, shadow and font values come from CSS variables / Tailwind theme tokens. No raw hex in components.
→ app/globals.css · tailwind.config.js
Mobile-first & responsive
Layouts are designed for small screens first, then enhanced at 900px and 1040px. No horizontal scroll except inside scoped scroll containers (tables).
→ see Responsive
Color carries meaning
The chrome is near-monochrome (onyx + neutrals). Saturated color is reserved: violet for interactive/brand, and the risk ramp (green/amber/red) exclusively for encoding risk severity.
Contrast minimum: WCAG 2.2 AA
Text ≥ 4.5:1 (large/UI graphics ≥ 3:1). Every foreground/background pair is measured, not eyeballed.
→ see Accessibility
Respect reduced-motion
Transitions are minimized under prefers-reduced-motion: reduce.

One accent only
Violet is the only interactive accent. Text-bearing surfaces use the #7c3aed/#6d28d9 pair; #a78bfa is decorative only (nav bar, glows).
Risk ramp uses AA-safe text pairs
Badges pair a tinted background with a darkened foreground: low #047857/#d1fae5, medium #b45309/#fef3c7, high #b91c1c/#fee2e2.
Muted text floor
Lightest body text is #6b7686 (4.6:1 on white) — never lighter.

03 Typography

Poppins throughout; tabular figures for data.

Family: Poppins
Three weights only: 400 body · 500 UI/controls · 600 headings & labels. Headings get presence from size + 600, not a heavier weight; tracking -0.02em.
Tabular numerals for data
Coordinates, risk ratings, years and pagination use font-variant-numeric: tabular-nums so columns align.
Micro-labels
Card titles & section labels: 11–12px, 600, uppercase, 0.06–0.1em tracking, secondary color.

04 Layout & spacing

A fixed sidebar and a fluid content column on an 8px rhythm.

Sidebar width 232px
Fixed, full-height, onyx gradient. Collapses to a slide-in drawer below 900px.
Content padding
26–32px desktop, tightening to 12–18px on mobile. Cards gap 16px.
Primary grid
Map + trend as 1.4fr / 1fr; stacks to one column below 1040px.

05 Radius & shadow

Radius scale
Cards 14px, controls (buttons/selects) 8px, pills & badges 999px, avatars 50%.
Shadow scale
Subtle (cards), medium (overlays), and a violet primary glow for active/elevated brand elements.

06 Motion

Fast transitions
Hover/active use 0.15s ease; the drawer uses 0.3s cubic-bezier(.4,0,.2,1).
Purposeful animation only
Motion is limited to hover/active and the drawer. No looping or decorative animation; all disabled under reduced-motion.

07 Components

shadcn/ui (Radix) primitives — Button, Card, Badge, Checkbox, Sheet — for accessible behavior; native elements where the platform already does it best (see Selects).

Icons
One icon set: Lucide, outline style only. Sized 16-22px, default 2px stroke, and they inherit currentColor — never a second icon library, never filled glyphs.
Buttons
Primary: violet vertical gradient + glow + white text. Secondary: white surface, border, secondary text. All have a visible focus ring.
Pills / filters
Toggle pills (risk factors), backed by a Radix Checkbox for keyboard + screen-reader support: off = white + border; on = violet fill + glow. Fully rounded.
Selects & inputs
Native <select> (best keyboard, mobile and a11y support out of the box), styled to 38px tall, 8px radius, with the border lightening to violet on hover.
Cards
shadcn Card. White, 14px radius, subtle border + shadow. Header = uppercase micro-label + count, divided from the body.
Badges
shadcn Badge with risk variants (low / medium / high) — tinted background + AA-safe text + a severity dot. Used for risk ratings.
Avatar
Circular photo with a white ring and a success-green online dot. Always has descriptive alt text.
Author speech bubble
Solid (never translucent) onyx bubble with a tail pointing at the avatar.

08 Data visualization

Map markers
Colored by risk ramp, white border for separation. Selected marker enlarges with a static violet ring.
Trend line
Single violet line with a soft secondary-tinted area fill; gridlines use the card border token.
Tables
Sortable headers expose aria-sort; numeric columns are tabular. Horizontal scroll inside the card on narrow screens — never breaks page layout.

09 Responsive

Three breakpoints, drawer navigation, and a flex-overflow guard.

Breakpoints
≤1040px grid → 1 column · ≤900px sidebar → drawer + mobile header · ≤520px filters stack full-width.
Drawer nav
Below the lg breakpoint the sidebar becomes a shadcn Sheet (Radix Dialog) — focus-trapped, Esc-to-close, dimmed overlay — opened from a fixed top header. Desktop keeps the static sidebar; both share one SidebarContent.
Flex overflow guard
The content column sets min-width: 0 so a wide table scrolls inside its container instead of stretching the page.
